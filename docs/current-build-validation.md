读写执行体抛异常时也会跳过 Signal。[匹配宿主源码](https://github.com/ppy/osu/blob/9a10d935b05a3b896f4bd811d620f2023331db93/osu.Game/Database/RealmAccess.cs#L489)

| 场景 | 任务结束后计数 |
|---|---:|
| 正常读取 / 正常写入（各一项） | 0 |
| 启动前取消读取 | 1 |
| 读取抛异常 | 1 |
| 写入抛异常 | 1 |

五项均符合上述预期，确认宿主的取消/异常计数缺口；未给原生方法安装补丁。
