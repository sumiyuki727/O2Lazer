# 原版对齐阶段收尾与构建规则复核

维护状态（2026-10-06）：原版对齐阶段历史收尾审查；当轮 1352 项过滤验证及暂缓/维护边界。后续曲库更新冻结与部署见 [最新复核](library-refresh-release-review.md)。
文档职责与最新状态入口见[索引](README.md)。

日期：2026-10-06。用户决定结束本次原版客户端对齐，其余差异暂缓。本报告审查当前
`master` 工作树中近期的判定、Jam/药丸、长条、KS、误差条、随机、EX 零血及宿主适配。
导入/存储只作相关回归与边界复核，不在本轮继续性能实验或启动新功能。

## 结论与范围

本次没有发现近期改动新增未批准的跨层引用、Core/Formats 宿主依赖或可直接删除的
重复原生实现。源码无需因这次复核改变玩法。原生能满足的路径仍直接使用；保留的
具体算法、桥接和补丁各有明确缺口，见下表及[补丁清单](compatibility-patches.md)。

这是已选范围的阶段结束，不是所有原版功能、设备、谱面、服务器行为都已复现，
也不是全项目重构完成。此前明确反馈的有界验收继续有效；EX 新结算、不对称显示等
未单独确认的实机表现保留证据边界，不再自动要求用户继续原版对照。

## 近期修改的责任与原生缺口

| 修改 | 所有者 | 复核结果与保留适配的理由 |
|---|---|---|
| 连续不对称判定、尾 BAD 25 tick | Core；Integration 换算原生生命周期包络 | 窗口仅由 Core 定义；不取整输入、不修改时钟，原生对称毫秒窗口不能表达该规则 |
| Jam 严格越界、原始 COOL 药丸进度、原始 BAD 头拒绝 | Core；Integration 翻译已解析结果 | 计分与长条继续条件分开；显示、Drawable 不重新判定，药丸后的 COOL 不抹掉原始头判 |
| KS 停旧重播与判后禁用 | Host/Audio | 复用原生 SampleChannel 与音源身份；原生误触/判定实例和列级回退不能提供所需共同声道政策，局部适配只作用于当前 O2Lazer 游玩 |
| tick 误差条与 BAD 黄色 | Integration 只读投影；Presentation 原生条形表适配 | 复用原生色块、标记、平均值、动画；原生无独立显示坐标/早晚范围接口，数值 UR 仍为毫秒统计 |
| MS 的 HT/DC/DT/NC 窗口补偿 | Host Mod；ManiaScore 轻量适配 | 使用原生 IManiaRateAdjustmentMod，类型门控仅让已转换的 MS 物件进入；不复制 Mania 窗口公式 |
| Random/R-Random/S-Random | Integration 变换；Host 设置；Presentation 菜单 | Random 直接走原生；原生缺少轮转/Panic。隐藏旧算法保留身份，原生 SettingsEnumDropdown 子类只筛菜单，无新增 Mod 管线 |
| 流速 3.5/4.5 与单括号格式 | Host 原生滚速；O2LazerStrings 模板 | 只补等价档位与文本格式，不改视觉时钟或音频速度。算法相关七项文本按用户约定固定英文 |
| EX 零血完整记录、锁血、F | Core 状态；Host 原生 ScoreInfo 输出 | Core 不认识 F/Realm。曲终采用原生 Rank.F，不调用会锁住实时评级的 FailScore；不触发 EX 提前退场 |
| F 历史成绩与回放 | Host/Replays；Persistence/Realm 接入 | Rank 已有持久化字段，Passed 为忽略字段；读取恢复临时状态，无新 schema/归档版本，未来个人记录按 F 排除 |
| 2026.1005.0 宿主适配 | 构建依赖 | 使用正式版 Game/Mania 与 Framework 2026.921.1，单 DLL/ruleset 身份不变；不修改只读参考检出 |

Core/Formats 仍是两个独立项目。其余层在一个宿主程序集内，以语义依赖检查治理，
不能将目录分开称为完全编译解耦。当前六条精确例外与两项跨层 partial 均有原生接缝
理由，本轮没有增加或扩大许可。[架构说明](clean-rewrite-architecture.md)是后续放置实现的依据。

| 未提交改动（A14） | 最近多轮增量仍在工作树；本轮不自动提交、推送或改写其他已完成变更，后续按可审查边界分批整理 |

## 原版对齐的关闭与暂缓清单

已选 C01–C06、F05 显示、F07 随机及 F14 新 EX 政策结束本轮开发。
C01 为连续不对称区间而非整数位置复刻，C06 为判前停旧重播且判后禁止重触发，
F14 为用户选定的完整原始数据与 F 结果政策，均为有意差异。

其余暂缓：C07 音量/声像曲线；F01 Jam/药丸 HUD、F02 中央判定文本、F04 Classic
长条模式、F06 原版遮挡、F08 曲风、F15 独立 KS/BGM 增益、F16 专属摘要，以及
滚速精确标尺等未选细节。默认/第三方皮肤的 Mania 判定文字或贴图继续保留，不能全局
替换为 COOL。3Key、教程、任务、对战、商城、Avatar/场景等独立客户端功能不进入
当前 custom ruleset 对齐范围，重新设计须另行确定产品目标。
