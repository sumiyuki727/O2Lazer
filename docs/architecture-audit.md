## 结论与边界

`O2Jam.Core` 和 `O2Jam.Formats` 是独立项目：前者只有 .NET 基础依赖，后者另需 `System.Text.Encoding.CodePages`。二者不引用 osu、Mania、Realm、UI 或彼此。当前宿主项目引用并在交付时合并它们；独立编译已成立，运行时仍是单 ruleset DLL。

`Integration`、`Host`、`Presentation`、`ManiaScore`、`Host/Persistence/Realm` 和 `Composition` 是同一宿主程序集内的职责目录，不是编译隔离的程序集。A12 约束本仓库实际源码依赖，保留 Host/MS 并列接入与五条明确接缝；设置和成绩显示仍用 partial 与 Realm 接入共同编译。“已完全解耦”不成立，A04 后端设计和 A11 运行期/客户端验证仍需继续。后续抽取应以可替换契约和测试为依据，避免仅改目录或命名空间。
