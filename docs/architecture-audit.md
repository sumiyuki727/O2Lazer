## 结论与边界

近期修改未新增未批准越层、Core/Formats 宿主依赖或无理由的自有原生替代。
Core 独立保存判定/计分/生命状态，Formats 只解码；Integration 翻译并承载具体谱面变换。
Host 优先使用原生轨道、声道、输入、计分/结果及 Mod 阶段；Presentation 只做显示适配。
具体复核与原生缺口见[近期责任表](recent-changes-review.md#近期修改的责任与原生缺口)。

Core/Formats 是独立项目，交付时合入一个 ruleset DLL。其余目录为同程序集职责区，
不是完全程序集解耦，两个 Realm partial 和原生模型共同编译仍存在。以后抽取共用
设施应由真实第二消费者验证，不能只改目录就承诺所有 custom ruleset 可直接使用。
