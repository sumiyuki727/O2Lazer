# 曲库更新版本冻结复核

日期：2026-10-06。范围为当前 master 累积实现，以及本轮确认的曲库更新、原生难度投影与通知呈现。原版玩法对齐的历史审查仍见 [recent-changes-review.md](recent-changes-review.md)，本页是后续冻结版本的状态入口。

## 保留的实现与责任

| 部分 | 所属层及选择 |
| --- | --- |
| OJN 解码和原始位置 | Formats 保留独立数据与解码；不依赖 osu、Realm 或显示 |
| O2Jam 判定、Jam/药丸、血量 | Core 独立规则；Host/Integration 翻译结果，原版对齐之外的功能不继续扩展 |
| 原生难度专用投影 | Integration 将 OJN 映射成最小 Mania 输入；Host 调用原生计算器，保持游戏对象、音频和星级输入分离 |
| 导入与单批预取 | Host/Library 组织内容身份、准备与进度；只预取一批，不保留全库 OJN 字节 |
| 并发及后置星级 | Host/Difficulty 有界队列和纯数据契约；实际模型查询、文件校验与提交只在 Realm 适配器 |
| 更新和清理 | Realm 复用原生文件存储、事务、待删除标记；缺失证明和实际路径重查保留，不删除成绩记录 |
| 通知与计数 | Host/Configuration 合并显示阶段，使用原生 ProgressNotification/TransformTo；更新计数按唯一内容源，文件摘要统计不变 |
| 本地化 | 新旧入口统一使用 O2LazerStrings；中英资源同步，随机算法固定英文例外保持 |

原生无法直接提供外部 OJN 的身份核对、文件损坏后自有缓存失效、双轨更新/星级进度和特殊判定，因此相关适配保留。目录分层不等于完全编译解耦；既有语义许可和跨层 partial 不在本轮扩大。

## 清理结果

- 删除通知合并后不可达的扫描/元数据/匹配/集合同步格式分支，以及仅供这些分支的七项中英资源和访问器。
- 撤回的部分数字分组及细分计时不在生产实现；撤回专用 benchmark 源已移除。仍适用于当前完整分组/原生查询的显式只读诊断夹具保留，普通测试不运行它们。
- 旧全库缺失扫描入口移除，当前更新仍使用事务内 MarkDeleted 的路径重查；测试覆盖当前入口。
- 原生计数变换保留，不引入自定义动画循环、第二套计时器或界面阶段控制数据库的行为。
- 更新文档索引和维护状态，历史 Hash、性能失败与玩法对照继续作为历史证据，不误写成当前安装版。

代码规范复核：本轮清理使用 var、既有集合表达式和解释理由的注释；UI 文本无新增硬编码，未触碰只读参考仓库，未打开或改写客户端原库。后端异常/日志文本不作为 UI 本地化入口。

## 保留风险与下一步

1. 后段路径查询仍随数据规模增长；已确认版本实测完整导入约 4 分 28 秒，普通无变化更新约 16–17 秒。这是用户日志证据，不是稳定性能承诺。
2. 原生文件完整校验、数据库事务及星级计算仍有耗时与竞争；不以取消完整校验、增大并发或未证实的查询替代作为默认优化。
3. 私有反射/IL 衔接仍依赖宿主版本及多 ruleset 组合，自动测试不替代升级后的真实动画和完整客户端验收。
4. Realm 已隔离，但模型耦合及两项跨层 partial 仍在；SQL/服务器存档设计尚未开始。
5. 宿主 AutoMapper 13.0.1 的既有 NU1903 仍保留；原生 API 兼容限制未解决。
6. 小型 KS 跳入音频中段的尾音重建继续按用户决定暂缓；原版未选功能不在此轮重新开启。

下一步先从现行 [问题清单](architecture-audit.md) 中确定范围；此次冻结不再自动开展曲库性能实验。任何 benchmark 仍须先取得用户授权。
