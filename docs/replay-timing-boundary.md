## 判定历史恢复契约（R07，2026-10-09）

Core 的 `O2JamGameplayState.Restore` 恢复本配置已生成的完整快照，并发布一次最终状态。
快照必须来自相同难度与零血继续策略；此接口用于可信内存状态，不是外部归档校验入口。
Core 不保存原生对象身份、历史队列或回放时钟，也没有依赖 osu 的撤销接口。

Integration 复用结果中已存在的 `Resolution.State`：尾部检查、移除和恢复为常数级路径，
不扫描历史、不重做判定。原生允许同帧结果非严格逆序撤销，因此非尾部仍按身份从后查找，
从删除点前的有效快照开始，仅重算剩余后缀的 RequestedAccuracy。该路径用没有 HUD
订阅的临时 Core 状态计算，然后恢复原有权威实例；每次实际撤销只发布一个最终快照，
未知/重复撤销不发布。非尾部查找和移除仍有线性成本，不承诺任意乱序撤销的总量均线性。

原生尚未撤销的结果保留原始 Type、药丸转换及 ScoreDelta/LifeDelta，以便原生成绩和
血量撤销已应用的事实。重算后的核心快照按结果引用身份临时缓存，只覆盖受影响的保留
后缀；后续尾部撤销优先使用此缓存，重新命中继续产生正常结果快照。正常前进不新增一份
快照或缓存写入；移除对应结果和 Reset 时释放缓存，不延长已撤销对象的持有周期。
同帧撤销完成后恢复保留历史的核心状态，后续判定仍由同一 Core 实例驱动。

本轮 113 项 Core 与 139 项宿主过滤回归通过（新增 23 项），覆盖完整快照、重新推进、
Pills/Jam、同帧乱序、EX/NX/HX、NF、原生统计/血量，以及既有长条对象池与回放测试。
100 条倒序撤销现为 100 次最终通知；此前原审查为 5050 次。没有运行计时 benchmark，
不能换算为具体毫秒或保证所有客户端 seek 听感；本轮尚未安装客户端 DLL。
正式 v5、judgement_version、原生推进/录制、Mania Score 和持久化字段均未更改。
