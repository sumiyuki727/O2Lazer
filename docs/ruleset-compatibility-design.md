# Ruleset 共存与补丁协调

更新：2026-10-07。目标宿主：osu!lazer 2026.1005.0。

## 边界与原则

优先使用原生扩展点。只有缺少满足行为要求的原生接口时才使用补丁，且各功能仍在
自己的层级管理目标方法和作用域。共存设施归 Host/Compatibility，不进入 Core 或格式模块。

共用 Harmony 能避免部分 detour 被覆盖，但不能解决多个 prefix 跳过原方法、结果替换、
transpiler 相互冲突等语义问题。未知规则集不自动接管；发现同名 Harmony 类型也不代表兼容。

## 当前职责

| 部分 | 责任 |
|---|---|
| O2JamPatchCoordinator | 接受明确指定的程序集；注册 prefix/postfix 和优先级；按补丁所有者记录实际运行时；处理后加载；按所有者回滚。 |
| O2JamBmsHarmonyCompatibility | 指定已验证的 BMS 程序集；供现有六个共享入口使用，不负责运行时生命周期。 |
| O2JamPatchRollback | 汇总回滚失败，维持必要补丁失败时禁止游玩的策略。 |
| 各功能补丁 | 选择原生缺口、作用范围、目标、优先级和安装失败策略。 |

协调器在执行 Patch 前登记运行时，确保部分安装失败仍可回滚。撤销只使用调用者的
Harmony ID，同时取消其待加载注册；失败的运行时记录保留以便再次撤销。所有者 ID
必须由本项目功能分配，不能借用其他规则集的 ID。原生安装路径使用本 ruleset 的 Harmony，
回滚也始终覆盖它。

程序集后加载只处理为该程序集明确登记的目标。不会遍历所有社区规则集自动补注册。
多个提供方仍需要显式选择和组合验证；这不是已支持任意数量规则集的承诺。

## BMS 专属部分

共享的六个入口为左上角物件统计、难度图标、Player.ImportScore、ScoreImporter.GetScore、
ScoreImporter.CreateModel 和 ScreenStack.Push。列表与版本证据见 [BMS 验证](bms-coexistence.md)。

工作谱面使用 BeatmapManager 的外层入口，避开 BMS 的内层缓存补丁。这属于具体入口选择，
不放进通用协调器。BMS 自定义结算页的行为仍由 BMS 实现，O2Lazer 不替它绘制图标。

## 新增 ruleset 适配流程

1. 对照实际安装 DLL 和原生源代码，列出共同修改的方法、运行时版本、补丁 ID 与执行行为。
2. 先缩小自己的作用域，或选择满足需求且冲突更少的原生入口。
3. 只有确定存在独立运行时冲突时，增加提供方适配器，明确程序集及共同目标；调用协调器。
4. 检查 prefix 跳过、返回值替换和优先级。需要 transpiler/finalizer 时另行设计，当前桥接不支持。
5. 使用独立进程验证双方加载顺序、双方玩法/统计/结算/回放，以及回滚不撤销对方 ID。
6. 三个及以上规则集组合单独验收，不从两方测试推导多方安全。

## 诊断与未覆盖范围

注册及回滚失败日志带所有者与运行时程序集。GetDiagnostics 返回协调器已接入目标的只读快照，
包含提供方、实际查询运行时及程序集版本、目标签名、注册状态、观察到的所有者与查询错误。
等待提供方加载时只查询本地回退运行时，并明确标为 WaitingForProvider；不会假装查询不存在的外部运行时。
注册前先记录失败状态，成功后更新；回滚成功移除相应记录。查询不改变注册或玩法状态。
总安装完成和明确提供方后加载完成时各写一轮 Verbose 日志，可搜索 O2Lazer patch registration。
游玩、预览、模式切换和每帧路径不轮询；其他程序集加载不触发元数据查询。
目前没有自动发现未知重叠目标、评估补丁语义、协商多个运行时版本或修复其他规则集全局副作用。
这不是全局补丁扫描器。Harmony 元数据只能证明登记存在，不能证明 detour 当前仍在执行；
共同所有者也不自动等于冲突，需结合方法语义与实际行为。当前不自动生成修复补丁。

本轮将现有 BMS 行为迁到通用协调器，不新增第三方支持或改变玩法。验收范围为所有者隔离、
注册撤销、BMS 双加载顺序、常规回归和分层检查；真实客户端全链路边界仍见 BMS 验证页。

## 本轮验证（2026-10-07）

1,390 项常规过滤测试通过，另有 BMS 两种加载顺序各 1 项通过。协调器与安装回滚的
9 项定向测试再次通过。分层检查零编译错误、零越层违规、零过期例外。
BMS 测试增加真实外部 Harmony 的登记与撤销检查，常规测试验证撤销一个所有者后
另一个所有者仍生效、重复回滚、已加载提供方回调与未知提供方拒绝。
本轮进一步覆盖快照独立性、待加载取消、诊断失败隔离及真实 BMS 运行时所有者查询。
这些测试不等于所有规则集组合的客户端验收。
